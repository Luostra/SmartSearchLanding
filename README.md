# SmartSearch

Адаптивный лендинг на Vue 3, TypeScript и Vite по фирменному оформлению SmartSearch.

## Запуск

Нужен Node.js 22.12+ (рекомендуется актуальная версия Node.js 22).

```sh
npm ci
npm run dev
```

Сборка и локальный просмотр production-версии:

```sh
npm run build
npm run preview
```

## Что реализовано

- Фирменные цвета, локальные шрифты Manrope и Sora. Sora используется в латинском названии; кириллица набрана Manrope.
- SVG-знак с исходными контурами, вступительной анимацией и реакцией на наведение. В покое используются исходные слои логотипа; при движении — динамическое пересечение контуров.
- Три интерактивных сценария: рюкзак, наушники, лампа. Сценарии и условные товары находятся в `src/data/scenarios.ts`.
- Адаптивная навигация, FAQ, состояния загрузки и ошибок, поддержка клавиатуры и `prefers-reduced-motion`.
- Изображения товаров — декоративные CSS-иллюстрации. Шрифты включаются в сборку.

## Границы демо

Демо распознаёт только три подготовленных запроса (без учёта регистра, повторных пробелов, ё/е и простой пунктуации). Остальные запросы предлагают выбрать пример. Карточки — условные данные, не актуальные предложения маркетплейсов. Задержка отображения иллюстрирует переход между состояниями, не вызов AI.

Настоящий поиск, каталог, покупка, регистрация и сбор заявок не подключены. Пользовательские запросы не отправляются на сервер и не сохраняются. Перед полноценным запуском потребуется интеграция API, обработка его ошибок и подтверждение доступных площадок. Ключи API нельзя помещать в клиентский код или переменные `VITE_*`.
